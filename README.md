# IBRA DL

تطبيق أندرويد لـ **البحث والاستماع والتحميل** من يوتيوب — بدون إعلانات.

- بحث عن أي أغنية أو فنان، واستماع مباشر
- تحميل MP3 (320/192/128) أو M4A أو فيديو MP4
- تشغيل أغاني الجهاز والتنزيلات
- قوائم تشغيل + المفضلة + سمعتها مؤخراً
- التشغيل يستمر بالخلفية حتى لو طلعت من التطبيق، مع أزرار التكرار والعشوائي بالإشعار
- تكرار الأغنية نفسها / تكرار القائمة / مؤقت إيقاف
- مشاركة رابط يوتيوب إلى التطبيق للتحميل مباشرة

برمجة وتطوير ابراهيم الخزرجي — https://ibraprogram.netlify.app/
